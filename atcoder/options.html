AtCoder → GitHub Sync

Scope it to only the atcoder_solution repo, with Contents: Read and write. Stored locally in your browser; never sent anywhere but api.github.com.
How to create the token
  1. Create an empty repo named atcoder_solution on GitHub (add a README so main exists).
  2. Go to GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → atcoder_solution.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate, copy the github_pat_... value, paste it above, click Save then Test connection.
